# Chirag Jivani – Portfolio

Static site, no build step. Files: `index.html`, `photo.jpg`, `Chirag_Jivani_Resume.pdf`.

## Host on GitHub Pages
1. Create a repository named `<your-github-username>.github.io` (public).
2. Upload all files from this folder to the root of the repository.
3. Go to **Settings → Pages**, set Source to **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. After a minute the site is live at `https://<your-github-username>.github.io`.

To update the resume, replace `Chirag_Jivani_Resume.pdf` with a file of the same name.
